Ashen Banner Achievements v4.1.0
================================

MOUNT SOURCE CLEANUP
- Mount cards no longer display database names, raw item IDs, lookup prompts,
  source confidence notes, or debug metadata.
- Acquisition text is displayed only when a source is present in the verified
  Turtle WoW / Vanilla source catalogue.
- Entries without a dependable source remain in the collection journal but
  show no source line.
- Source text is rendered as a clean, two-line "Source:" field.
- Old source strings stored in SavedVariables are ignored.

MINIMAP BUTTON
- Added a packaged Ashen Banner achievement crest texture.
- The button still supports click-to-open and drag-to-position.

MY STATS - REPUTATION
- Tracks positive reputation gains for Today, This Week, Season, and All Time.
- Tracking begins with the first login snapshot after installing this version;
  pre-install historical gains cannot be reconstructed by the 1.12 client.
- This Week runs Monday through Sunday.
- Officers can begin a new reputation season from My Stats.
- Collapsed reputation headers are temporarily read and then restored, so the
  character reputation panel is not left expanded by the tracker.
